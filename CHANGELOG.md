# Изменения

## 0.1.0

- Тёмная русская панель с очередью, поиском, журналом и карточкой файла.
- Настройка путей для других компьютеров без привязки к аккаунту разработчика.
- Локальный MITM только для процесса Яндекс Диска, без нового OAuth.
- Наблюдение, ограничение повторов и обратимое откладывание полностью облачных файлов.
- Подтверждение сертификата перед включением; индивидуальный ключ каждой установки.
- Постоянный счётчик новых завершённых загрузок через Cloud Files API.
- Ручное включение и выключение без часового таймера.
- Отдельная команда восстановления и исключение личных данных из Git.
