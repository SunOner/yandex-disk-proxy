# Yandex Disk Proxy

[English](README.md)

Локальная панель для настольного Яндекс Диска. Показывает, какие файлы уже скачаны, какие остаются в очереди и где возникают ошибки.

Я сделал этот проект, когда часть файлов на моём Диске стала недоступна. В официальном приложении не хватало информации, чтобы понять, что продолжает скачиваться, а какие файлы застряли с ошибкой. Панель позволяет посмотреть состояние отдельных файлов, журнал запросов и историю загрузок, чтобы разобраться, что происходит с синхронизацией.

## Запуск

Нужны Windows 10/11 x64 и Яндекс Диск 4.

1. Скачайте **YandexDiskProxy.exe** из [последнего релиза](https://github.com/SunOner/yandex-disk-proxy/releases/latest) и запустите. Python не требуется.
2. Откройте панель **http://127.0.0.1:18765** и включите тумблер прокси.
3. Если пути не определились автоматически, выберите папку синхронизации и `YandexDisk4.exe` кнопками **«Обзор…»**, затем включите тумблер ещё раз.
4. При первом включении подтвердите временное доверие сертификату в панели. Рекомендуемый автоматический режим устанавливает его в доверенные корневые сертификаты компьютера Windows через небольшой помощник; подтвердите запрос прав администратора Windows, если он появится. Пока сертификат установлен, ему могут доверять приложения всех пользователей. При остановке прокси удаляет добавленное им доверие; существовавшее ранее доверие сохраняется. Ручной импорт сертификата и дополнительный вход в аккаунт не нужны. Системные настройки прокси не меняются.

**Настройки** открывают отдельную вкладку с автоматической установкой сертификата, состоянием доверия, выбором хранилища и дополнительными действиями установки, удаления и скачивания. Хранилище текущего пользователя доступно для совместимости; на некоторых системах Windows или клиент Диска могут отклонять такое доверие. После смены хранилища нужно снова подтвердить доверие для выбранной области.

Оставьте консоль открытой на время работы прокси. Вкладку браузера можно закрыть.

## Работа с ошибками

Панель отслеживает файлы с отметкой **«Хранить на компьютере»**.

| Режим | Действие |
| --- | --- |
| Откладывать файлы | После HTTP 500 временно снимает отметку хранения, чтобы клиент мог перейти к другим файлам. |
| Ограничивать повторы | Приостанавливает повторные запросы без изменения отметок хранения. |
| Наблюдать | Записывает события без изменения запросов и отметок. |

Частично скачанные и изменённые файлы не откладываются. При смене режима откладывания или остановке прокси исходные отметки восстанавливаются. Прокси не может восстановить данные, которые серверы Яндекса не отдают.

**«Запросы и журнал»** показывает подробности запросов и ошибки. **«Мониторинг»** — историю загрузок и сетевых показателей; статистика сохраняется между перезапусками.

## Прямые загрузки

Нажмите **«Скачать…»** у файла или откройте **«Прямые загрузки»**, чтобы попробовать свежую ссылку Яндекса, готовый URL или загрузку через браузер.

Прямая очередь сохраняет проверенные файлы в `%USERPROFILE%\Downloads\Yandex-Recovery\<папка Диска>`. Эти файлы находятся отдельно от папки синхронизации и учитываются отдельно от загрузок клиента. Прямая ссылка тоже может не сработать, если сервер не отдаёт файл.

## Остановка и восстановление

Выключите тумблер прокси или закройте консоль. Программа вернёт отложенные файлы в очередь и перезапустит Диск без прокси. При ошибке восстановления повторите действие тумблером. После прерванного сеанса запустите EXE снова или выполните:

```powershell
.\YandexDiskProxy.exe --recover
```

## Локальные данные

Настройки, сертификаты, статистика и журналы хранятся в `%LOCALAPPDATA%\YandexDiskProxy`. Не удаляйте эту папку до завершения восстановления.

Токены по умолчанию скрыты. В сохранённых журналах и архиве диагностики данные авторизации замаскированы; имена и пути файлов остаются. Содержимое файлов не записывается. Старые журналы удаляются по мере ротации.

## Сборка из исходников

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe build_windows.py
```

Результат: `release\YandexDiskProxy.exe`. Перед заменой закройте работающий прокси. Сохраняйте прежний путь к EXE, если используете раздельное туннелирование VPN.
